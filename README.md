# MixMaster: Сервис склейки MP3 с умными переходами

## Суть проекта
Веб-сервис, позволяющий пользователям загружать любое количество MP3-файлов, выстраивать их в нужном порядке и объединять в единый микс с помощью FFmpeg (кроссфейд `acrossfade`).
Встроенный плеер позволяет прослушать результат. Дополнительно интегрирован ИИ (LLM), который анализирует метаданные (ID3-теги) и предлагает креативное название для микса.

## Архитектура
*   **Бэкенд:** Python, FastAPI. Обработка аудио через `subprocess` (FFmpeg). Асинхронная обработка запросов.
*   **Фронтенд:** Vanilla JS, CSS. Адаптивный дизайн.
*   **CI/CD:**
    *   `01-quality.yml`: Проверка кода линтером (Ruff) и юнит-тесты (Pytest) логики склейки и парсинга метаданных.
    *   `02-project.yml`: Project CI. Автоматически генерирует тестовые аудиофайлы, склеивает их через код проекта и сохраняет итоговый `demo_mix.mp3` в артефакты.

## Запуск локально
1. Установите FFmpeg (`sudo apt install ffmpeg` или скачайте с сайта ffmpeg.org).
2. `pip install -r requirements.txt`
3. `uvicorn app.main:app --reload`
4. Откройте `http://localhost:8000`

## Что создано в рамках задания
Вся структура проекта, код интеграции FFmpeg, фронтенд, тесты и оба workflow написаны с нуля для этого задания.
