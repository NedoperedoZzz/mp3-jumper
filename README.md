# MixMaster: Сервис склейки MP3 с умными переходами

## Суть проекта
Веб-сервис, позволяющий пользователям загружать любое количество MP3-файлов, выстраивать их в нужном порядке (с помощью Drag-and-Drop) и объединять в единый микс.
Сервис поддерживает два режима склейки: быстрый (через FFmpeg `acrossfade`) и умный (через `pyCrossfade` с анализом BPM). Встроенный плеер позволяет прослушать результат и увидеть тайм-коды смены треков. Дополнительно интегрирован ИИ (локальная LLM через Ollama), который анализирует метаданные (ID3-теги) и предлагает креативное название для микса.

## Архитектура
*   **Бэкенд:** Python, FastAPI. Обработка аудио через `subprocess` (FFmpeg) и библиотеку `pycrossfade`.
*   **ИИ-интеграция:** `ollama` (модель `llama3.2:1b` по умолчанию).
*   **Фронтенд:** Vanilla JS, CSS. Адаптивный дизайн, Drag-and-Drop, кастомный аудиоплеер.
*   **CI/CD (GitHub Actions):**
    *   `01-quality.yml`: Проверка кода линтером (Ruff) и юнит-тесты (Pytest) логики склейки (с моками) и парсинга метаданных. Запускается автоматически на `push`.
    *   `02-project.yml`: Project CI. Автоматически генерирует тестовые аудиофайлы с помощью FFmpeg, склеивает их через реальный код проекта и сохраняет итоговый `demo_mix.mp3` в артефакты. Запускается вручную (`workflow_dispatch`).
    *   `03-pages.yml`: Деплой фронтенда на GitHub Pages (`static/` → артефакт `github-pages` → `deploy-pages`).

## Опубликованная страница и бэкенд

Фронтенд доступен по адресу GitHub Pages, но там **только статика**: склейка и генерация
названий обращаются к FastAPI, которого на Pages не существует. Поэтому опубликованная
страница по умолчанию работает как витрина — при загрузке она опрашивает `/api/health` и
честно показывает статус в плашке под заголовком.

Чтобы фичи заработали на опубликованной странице, бэкенд поднимается на Render/Fly
(`render.yaml` + `my_container.dockerfile` уже в репозитории), а его адрес прописывается
в `static/index.html`:

```js
window.MP3_API_BASE = "https://<your-service>.onrender.com";
```

Подробности, переменные окружения и ограничения бесплатных тарифов — в [docs/BACKEND.md](docs/BACKEND.md).
Модель для названий переключается между локальным Ollama и облачным OpenAI-совместимым API
переменной `LLM_PROVIDER`; при недоступной модели API отдаёт 503 с причиной, а не видимость успеха.

## Запуск локально
1. Установите FFmpeg (`sudo apt install ffmpeg` или скачайте с сайта ffmpeg.org).
2. Установите и запустите Ollama (скачайте с ollama.com), выполните `ollama run llama3.2:1b`.
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите сервер: `uvicorn app.main:app --reload`
5. Откройте `http://localhost:8000`
