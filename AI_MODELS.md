# Декларация использования моделей ИИ

**Статус:** ИСПОЛЬЗОВАЛ

| Точное название модели | Сервис / провайдер | Этап и цель использования | Как повлияла на результат |
|---|---|---|---|
| Gemini 2.5 Pro | Google AI Studio | Написание архитектуры бэкенда (FastAPI), логики FFmpeg, скриптов CI/CD и фронтенда | Ускорила разработку, предоставила шаблоны для `acrossfade` и настроек GitHub Actions |
| Модель неизвестна (API пользователя) | По выбору пользователя (OpenAI/Ollama) | Работающее приложение: генерация креативного названия для итогового микса | Интегрирована в `app/llm.py` как функция, вызываемая по кнопке на сайте |

*Примечание: Полные переписки и API-ключи не публикуются в целях безопасности.*
