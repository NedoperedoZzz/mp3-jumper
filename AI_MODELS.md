# Декларация использования моделей ИИ

**Статус:** ИСПОЛЬЗОВАЛ

| Точное название модели | Сервис / провайдер | Этап и цель использования | Как повлияла на результат |
| --- | --- | --- | --- |
| DeepSeek-V4.1-Flash-1017 | DeepSeek | Написание архитектуры бэкенда (FastAPI), логики FFmpeg, скриптов CI/CD и фронтенда | Ускорила разработку, предоставила шаблоны для `acrossfade`, работы с `subprocess` и настроек GitHub Actions |
| Llama 3.2 (1B) | Ollama (локальный запуск) | Работающее приложение: генерация креативного названия для итогового микса на основе метаданных треков | Интегрирована в `app/llm.py` как функция, вызываемая по API-запросу с фронтенда при нажатии кнопки «Сгенерировать ИИ» |
| Llama 3.2 (1B) в облачном режиме (`meta-llama/llama-3.2-1b-instruct:free`) | OpenRouter (OpenAI-совместимый API, включается `LLM_PROVIDER=openai` в `app/llm.py`) | Работающее приложение на хостинге: тот же генератор названий микса, когда локального Ollama рядом нет (GitHub Pages + Render) | Альтернативный провайдер в одном коде; строку можно удалить, если облачный режим не используется |
| **Qwen3.8-Max** (в режиме Agent) | Alibaba Cloud (Qwen) | Автоматическое создание и применение двух патчей: `0001-fix-pages-split-build-deploy-jobs-gate-on-artifact-v.patch` (исправление workflow `03-pages.yml` для корректного деплоя на GitHub Pages) и `backend-cloud-llm.patch` (добавление в бэкенд поддержки облачной LLM и разделение build/deploy job'ов); консультации по диагностике ошибок Actions, `git am`, доступности Render/OpenRouter в РФ, настройке Cloudflare Tunnel и российского VPS | Два готовых `.patch`-файла применены в репозитории; workflow деплоя и облачный LLM-провайдер в бэкенде — результат работы агента |
| **Qwen4-Max** | Alibaba Cloud (Qwen) | Полный рефакторинг фронтенда на бессерверную склейку (v2.1: Web Audio API для декодирования + lamejs для кодирования MP3, корректные кроссфейды); написание провайдера GigaChat в `app/llm.py` (OAuth-токен с 30-минутной жизнью, CA-бандл НУЦ Минцифры); помощь с моками в `tests/test_llm.py` и исправление тестов под импорты; разбор ошибок `UnicodeEncodeError` при неверном ключе авторизации; консультации по тарифам Amvera | Клиентская склейка без повторов первого трека, рабочий провайдер GigaChat, 18 зелёных тестов, полностью бесплатное публичное развёртывание без хостинга |

Примечание: Полные переписки и API-ключи не публикуются в целях безопасности. Ключ облачного провайдера задаётся только переменной окружения `LLM_API_KEY` (в репозитории его нет); ключ GigaChat — `GIGACHAT_AUTH_KEY` (аналогично не попадает в git).
