# Декларация использования моделей ИИ

**Статус:** ИСПОЛЬЗОВАЛ

| Точное название модели | Сервис / провайдер | Этап и цель использования | Как повлияла на результат |
|---|---|---|---|
| DeepSeek-V4.1-Flash-1017 | DeepSeek | Написание архитектуры бэкенда (FastAPI), логики FFmpeg, скриптов CI/CD и фронтенда | Ускорила разработку, предоставила шаблоны для `acrossfade`, работы с `subprocess` и настроек GitHub Actions |
| Llama 3.2 (1B) | Ollama (локальный запуск) | Работающее приложение: генерация креативного названия для итогового микса на основе метаданных треков | Интегрирована в `app/llm.py` как функция, вызываемая по API-запросу с фронтенда при нажатии кнопки «Сгенерировать ИИ» |
| Llama 3.2 (1B) в облачном режиме (`meta-llama/llama-3.2-1b-instruct:free`) | OpenRouter (OpenAI-совместимый API, включается `LLM_PROVIDER=openai` в `app/llm.py`) | Работающее приложение на хостинге: тот же генератор названий микса, когда локального Ollama рядом нет (GitHub Pages + Render) | Альтернативный провайдер в одном коде; строку можно удалить, если облачный режим не используется |

*Примечание: Полные переписки и API-ключи не публикуются в целях безопасности. Ключ облачного провайдера задаётся только переменной окружения `LLM_API_KEY` (в репозитории его нет).*
