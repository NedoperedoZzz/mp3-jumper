# Идеи для творческого Project CI

Это примеры, а не ограниченный перечень тем. Сложные технологии сами по себе не дают бонусных баллов: важен полезный результат и обоснованная автоматизация.

| Направление | Идея | Полезный результат CI |
|---|---|---|
| Agent Harness | Агент выполняет многошаговую задачу и возобновляет работу из checkpoint | trace.jsonl, checkpoint, патч или итоговый файл |
| MCP / разработка | Проверяющий конфигураций, помощник для репозитория, анализатор кода | отчёт о проблемах и исправлениях |
| NLP | Классификация документов, тематическая группировка, извлечение фактов | JSON/CSV + краткий отчёт |
| ML | Обработка данных, обучение небольшой модели, анализ сдвига распределений | модель, метрики, графики |
| Документы | Генерация документации, отчетов, changelog по входным данным | HTML/Markdown/PDF или публикация |
| Веб | Сборка интерактивной страницы из данных | GitVerse Pages или HTML-артефакт |
| Мониторинг | Мониторинг состояния проекта/зависимостей по расписанию | новый структурированный отчёт |

**Для Harness:** допустим openJiuwen или Mini-Harness. Не требуется запуск большого агентного сервиса на постоянной основе; достаточно ограниченного пакетного процесса в CI. Особое внимание уделить состоянию, ограничению инструментов и содержательному trace.

**Для LLM-проектов:** не публикуйте секреты и пользовательские данные в артефактах. Учитывайте квоты API и предусматривайте ограниченный, воспроизводимый сценарий.

**Для прежних проектов:** не просто перенесите старый код; обозначьте новый вклад — например, интеграцию данных, многозадачную автоматизацию, публикацию результата или полноценный агентный цикл.
