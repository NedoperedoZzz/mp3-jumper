# Идеи творческих проектов (не список обязательных вариантов)

Тема, язык, библиотеки и площадка свободны. Важно, чтобы Quality CI проверял **реальные свойства вашего проекта**, а Project CI **создавал полезный результат**.

| Направление | Возможная идея | Project CI делает | Одна из содержательных Quality-проверок |
|---|---|---|---|
| Agent Harness | Агент запоминает прогресс между сессиями | Прогон сценария; trace, checkpoint, результат | Восстановление состояния и ограничения инструментов |
| MCP / Developer Tools | Анализатор конфигураций или MCP-инструменты | Отчёт, патч или результат вызовов | Проверка контракта инструмента |
| NLP | Извлечение фактов, классификация, обзор текстов | JSON/CSV + отчёт | Проверка обработки пустых и нестандартных входов |
| ML | Анализ данных или небольшая модель | Метрики, модель, визуализация | Проверка входной схемы и корректности обработки |
| Документы | Генератор changelog, документации, отчётов | Файл или публикация из исходных данных | Проверка структуры созданного документа |
| Веб | Интерактивная панель или визуализация | Сборка и публикация сайта | Проверка сборки и сценария пользовательского интерфейса |
| Мониторинг | Регулярный анализ состояния системы | История измерений / отчёт о событиях | Проверка парсинга и обработки ошибок |
| Своя идея | Любой полезный программный инструмент | Объяснимый результат | Осмысленная проверка существенного свойства |

## Если хочется Harness

Можно использовать openJiuwen, другой фреймворк или собственный Mini-Harness. Интересны контекст, tool policy, ограничение бюджета шагов, возобновление работы, журнал вызовов. **Само использование фреймворка дополнительных баллов не даёт**.

## Если используется прошлый проект

В README и SUBMISSION.md опишите, **что было раньше и что добавлено сейчас**. Например, развитие функционала, новые способы получения результата, автоматизация ранее ручного процесса, содержательные проверки, публикация или агентный workflow. Перенос старого репозитория без нового вклада не является выполнением задания.
